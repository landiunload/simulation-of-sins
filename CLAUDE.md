# Память проекта Simulation of sins

- Это новая игра с чистого листа. Код и ассеты старой `laiue-game` не
  переносятся автоматически.
- Игра использует только установленный публичный SDK `laiue` через
  `find_package`; внутренние заголовки и исходники движка недоступны.
- Игровые правила, authored content, сохранения и будущая сеть принадлежат
  игре. Повторно используемый функционал получает независимый контракт и
  переносится в `laiue` вместе с тестами.
- Пока поддерживается Windows x86_64: MSVC и clang-cl, Debug и Release.
- Ответы по проекту ведутся на русском языке.
