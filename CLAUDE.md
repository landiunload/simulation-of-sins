# Память проекта Simulation of sins

- Ответы по проекту ведутся на русском языке.
- Игра — симулятор жизни в бесконечном объёмном 3D-мире на движке
  [landiunload/laiue](https://github.com/landiunload/laiue). Сейчас в
  репозитории только основа приложения; дизайн игры наращивается поэтапно,
  и по каждому открытому вопросу дизайна нужно спрашивать автора.
- Движок клонируется рядом (`../laiue`) и по умолчанию собирается вместе с
  игрой; заранее собранный SDK выбирается явным `laiue_DIR` — так его
  проверяет CI. Без соседа configure скачивает `SOS_ENGINE_REVISION`.
- Игра линкует только `laiue::bootstrap` и загружает модули движка по имени.
  Каждый модуль необязателен, и игра обязана работать без любого из них.
- `src/sim` — детерминированное ядро без движка, `src/app` — жизненный цикл и
  модули, `src/client` — представление. Повторно используемое уходит в
  движок с тестами.
- Решения автора: ×1 — реальное время, ускорение до года в секунду и
  замедление до остановки; рельеф правится с шагом 0,5 м; графика пока
  макет; первая веха — мир и два человека, дальше механики добавляются
  понемногу, первой — ягодные кусты.
- Устройство, правила и проверки — в [docs/architecture.md](docs/architecture.md)
  и [CONTRIBUTING.md](CONTRIBUTING.md).
