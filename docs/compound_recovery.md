# Восстановление составных физических объектов — 13 сентября 2026

Перед исправлением сохранены все семь изменённых файлов игры в
`build/recovery-20260913-construct/` (включая прежние незакоммиченные оптимизации).
Это локальная резервная копия, не git commit; она не удалена.

## Причина

Спавнер рисовал буквы из блоков, но collider оставался сплошным кубом.
Новые постройки считались вторым осевым AABB-решателем с double-позицией,
без вращения и со временем шага, зависимым от кадра. Два набора тел не
сталкивались друг с другом. В распаде при исчерпании слотов терялись блоки.

## Разделение ответственности

- Движок: составная rigid-форма из локальных коробок, COM, полный тензор,
  contacts, вращение, сон, фиксированный шаг и точные координаты.
- Игра: сетка блоков, материалы, связность, достройка/разрушение и распад,
  общий владелец тел `SimulationCubeField` и команды редактирования.
- Клиент: инстансы отдельных блоков из настоящей физической позы, группировка
  по материалам, ближайшее препятствие для луча, rebasing всех тел ровно один раз.

Кубам возвращён прежний меш; улучшения роста буферов и persistent-кэшей сохранены.
Предел спавна 1000 из неудачной попытки удалён. После изменения мира
инвалидируются warm-start и сон, чтобы тело не висело над удалённой опорой.

## Итоговая проверка

После hardening прошли следующие актуальные проверки:

- Windows MSVC Debug и Release: все 40 тестов движка в каждом конфиге, включая compound physics,
  D3D12/Vulkan lifecycle и dual-backend; игра с обоими backend — 10/10.
- Windows clang-cl Debug и Release с clang-tidy: source-superbuild игры и
  движка — 19/19 в каждом конфиге. Это включает game replay, compound physics,
  рендерные smoke-тесты и архитектурную проверку 105 файлов.
- Linux GCC Debug с ASan/UBSan: игровой тест и отдельный compound test прошли;
  AddressSanitizer не нашёл утечек после двух fresh replay стержня из 256 блоков.
- Linux GCC Release с LTO: игровой тест и compound test прошли; compound replay
  совпал с MSVC и clang-cl: `0x6b06a6294d01137d`.
- Linux EXTERNAL/static source-superbuild: финальная линковка всего игрового
  ядра и модулей движка через `WHOLE_ARCHIVE` и запуск smoke прошли в Release
  с LTO/GC и в Debug без LTO/GC. Исправлена скрытая ошибка CMake: выбор этой
  проверки теперь опирается на `TYPE` публичной цели `laiue::physics`, а не на
  внутренние переменные движка, недоступные после `add_subdirectory`.
- Windows ARM64 clang-cl: Debug и Release `laiue_physics` и compound test
  скомпилированы и слинкованы без CRT. Это link-closure, не запуск на ARM64.

Регрессии проверяют 16-блочную плиту с числом опор больше 16, L-формы с
настоящей пустотой, разрушение креста на шесть независимых фрагментов,
атомарный отказ полного пула и повторяемость 384 фиксированных тиков в
canonical и colored solver. Отдельный 256-блочный стержень, чей повёрнутый
envelope превышает бюджет 4096 клеток, теперь имеет контакт с миром и не
проваливается сквозь пол.

Повторные read-only рецензии DeepSeek 4.1 Flash через OpenCode проверили
уникальность слотов/ID/форм при распаде, подготовку и фиксацию изменений,
границы scratch и детерминированный порядок обхода большого compound.
Новых подтверждённых дефектов в этих путях после исправлений не найдено.

Интерактивный Release-клиент также дважды запускался со спавнером на каждом
backend: D3D12 и Vulkan. В повторном десятисекундном запуске код завершения
обоих процессов — 0; CSV подтвердили запрошенный backend и рост сцены примерно
до 1000 тел. Логи: `build/compound-scene-final-{d3d12,vulkan}.*`.
Это smoke-проверка, не стабильный FPS-бенчмарк: повторные окна запускались
со скрытым начальным состоянием, и интервалы кадров отличаются от обычного
запуска. В исходном оконном прогоне около 1000 тел физический тик занимал
примерно 4–5 мс; это не подтверждает производительность на сотнях тысяч тел.

Сотни тысяч одновременно активных составных тел, CCD, нативный runtime
macOS/mobile/консольных платформ этими прогонами не подтверждены. Зелёный replay
подтверждает этот набор фиксированных сценариев, а не отсутствие любых будущих
физических артефактов.
